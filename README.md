# アプリ概要

Todoアプリ「TaskTracker」のURL：[https://komaaaaa0311.github.io/TaskTracker/](https://komaaaaa0311.github.io/TaskTracker/)

TaskTrackerは、日常生活のタスクを効率よく管理するためのTodoアプリです。

React、TypeScript、Tailwind CSSを使用して開発しました。タスクの追加や完了状態の管理、優先度や期限の設定ができます。

また、ブラウザのローカルストレージを利用してデータを保存するため、ページを再読み込みしたりブラウザを閉じたりしても、登録したタスクを保持できます。

GitHub Pagesを利用して公開しており、Webブラウザから無料で利用できます。

まず上部のリンクにアクセスしてください。


# 開発動機

日々の生活の中で、提出しなければならない課題や予定、買い物など、やらなければならないことを忘れてしまい、結果として不便を感じたり、損をしてしまったりすることが度々あった。特に、複数の予定やタスクが重なると、何をいつまでに終わらせる必要があるのかを把握することが難しくなり、やり忘れにつながることがあった。そこで、このような日常生活におけるタスクのやり忘れを減らし、やるべきことを効率よく管理できるようにするために、タスク管理アプリを作成しようと考えた。

# 使用技術

| 使用技術 | 用途 |

| Tailwind CSS | デザインやレイアウトの調整 |
| Vite | 開発環境の構築とビルド |
| LocalStorage | タスクデータの保存 |
| Git / GitHub | ソースコードのバージョン管理 |
| GitHub Pages | Webアプリの公開 |
